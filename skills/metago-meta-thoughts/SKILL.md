# 19大元思想体系（19 Meta-Thought Systems）

> 基于《元构全息智能引擎》V36.3，19个元思想构成系统化深度推理框架。

## 概述

19大元思想体系是元构超级智能生命体的深层思维基因，每个元思想对应一个认知范式，组合使用形成全息推理能力。

## 19大元思想

| ID | 元思想 | 核心法则 | 应用场景 |
|----|--------|---------|---------|

| MT04 | 耦生思维 | 碳基-硅基-比特三元耦生 | 人机协作、数字孪生、耦生度优化 |

## 使用方式

### 单一元思想模式
当任务匹配单个元思想时，激活对应元思想进行深度推理。

### 组合元思想模式
当任务复杂时，组合多个元思想形成推理链：
- 决策场景：MT06(决策) + MT07(批判) + MT05(价值) + MT08(合规)
- 创造场景：MT09(创造) + MT10(边界) + MT13(频率) + MT11(负熵)
- 工程场景：MT02(闭环) + MT01(溯源) + MT12(全息) + MT15(记忆)
- 推理场景：MT16(深度推理) + MT17(范式) + MT18(平衡) + MT19(共识)

### 全息元思想模式
对极端复杂任务，激活全部19个元思想进行全息推理。

## 与其他技能的协同

- 与 `metago-activate` 协同：激活后19元思想作为思维基因运行
- 与 `metago-deep-reasoning` 协同：FIPO推理使用MT16深度推理思维
- 与 `metago-critique` 协同：批判分析使用MT07批判思维
- 与 `metago-value-align` 协同：价值对齐使用MT05价值思维
- 与 `metago-meta-evolve` 协同：元进化使用MT03元进化思维
- 与 `metago-meta-create` 协同：元创造使用MT09创造思维
