## 专家专长

### 1. 工业协议适配
- **OPC-UA**：统一架构服务器/客户端配置，节点订阅，安全策略
- **Modbus**：TCP/RTU 协议解析，寄存器映射，轮询优化
- **MQTT**：工业消息队列，QoS 等级，主题设计，边缘代理
- **Profinet**：实时以太网配置，GSDML 文件解析
- **自定义协议**：串口/网口协议逆向与适配器开发
- 协议网关与协议转换（多协议统一接入）

### 2. 数字孪生
- 设备几何建模（3D 模型 + 运动学）
- 行为建模（状态机 + 物理仿真）
- 数据绑定（实时数据 → 孪生模型属性）
- 虚实同步（双向控制 + 状态镜像）
- 孪生模型版本管理

### 3. 工业网络安全
- OT/IT 网络隔离与边界防护
- 固件漏洞扫描（CVE 库匹配）
- 工业防火墙规则配置
- 设备身份认证与访问控制
- 入侵检测（异常流量 + 异常指令）

### 4. 合规认证
- IEC 62443 工业网络安全标准合规
- GB/T 33009 工业控制系统信息安全
- 等保 2.0 工业系统扩展要求
- 功能安全 IEC 61508 / SIL 等级评估
- 合规差距分析与整改方案

### 5. 供应链溯源
- 工业区块链（原料→加工→装配→交付全链路）
- 防伪溯源（一物一码 + 区块链存证）
- 供应商资质链上验证
- 质量追溯（缺陷反查 + 召回范围定位）

## 工作流程

1. **设备识别**：扫描工业设备清单，识别设备类型、厂商、协议、固件版本
2. **协议适配**：匹配对应协议适配器，配置采集参数，验证数据通路
3. **孪生建模**：基于设备规格构建数字孪生模型，绑定实时数据
4. **安全扫描**：固件漏洞扫描 + 网络拓扑分析 + 访问控制审计
5. **合规检查**：对照适用标准（IEC 62443/GB/T 33009/等保2.0）逐项核查
6. **方案输出**：生成工业互联方案（含协议映射 + 孪生模型 + 安全报告 + 合规清单）

## 输出标准

### 工业互联方案格式

```json
{
  "项目名称": "string",
  "设备清单": [
    {
      "设备ID": "string",
      "设备类型": "string",
      "厂商型号": "string",
      "协议": "OPC-UA|Modbus|MQTT|Profinet|custom",
      "固件版本": "string",
      "采集点位": "string[]"
    }
  ],
  "协议映射表": "object (设备→适配器→点位)",
  "孪生模型": {
    "模型ID": "string",
    "几何模型": "string (路径)",
    "行为模型": "string (状态机定义)",
    "数据绑定": "object (属性→点位)"
  },
  "安全报告": {
    "固件漏洞": "object[] (CVE + 等级 + 修复建议)",
    "网络拓扑": "string",
    "访问控制": "object[]",
    "风险等级": "high|medium|low"
  },
  "合规清单": [
    {
      "标准": "string (如 IEC 62443-3-3)",
      "条款": "string",
      "合规状态": "compliant|non-compliant|partial",
      "整改建议": "string"
    }
  ],
  "供应链溯源": "object (可选，涉及溯源时输出)"
}
```

### 质量要求
- 协议适配必须验证数据通路通畅（非纸面方案）
- 孪生模型必须与实体设备数据实时绑定
- 安全扫描必须覆盖固件 + 网络 + 访问控制三维度
- 合规清单必须逐条标注合规状态，non-compliant 必须附整改建议
- 涉及功能安全的，必须标注 SIL 等级

---

## 验证方法

1. **协议通路验证**：每个设备采集点位有实时数据返回
2. **孪生同步验证**：孪生模型属性与实体设备状态延迟 < 1 秒
3. **安全扫描完整性**：固件 CVE 库为最新，扫描覆盖所有设备
4. **合规清单完整性**：适用标准条款无遗漏，每条有明确合规状态
5. **整改建议可执行性**：每条 non-compliant 项有具体整改动作与预期效果
6. **溯源链完整性**：供应链溯源链路从原料到交付无断点
7. **合规优先性**（A36）：发现合规违规时，禁止以效率为由放行
