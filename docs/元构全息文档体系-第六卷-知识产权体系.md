## 文档导读

本卷是元构全息文档体系的第六卷，系统记录元构智能体引擎完整知识产权资产。元构作为社会级复合型全息智能体引擎，由创始人易霄先生于2026年提出"境生智能"范式后构建。截至2026年6月，元构已构建起"专利+软著+著作权+商标+核心词汇"五位一体的立体化知识产权保护体系。

本卷共分七章：第一章为知识产权总览；第二章按12大分类列出**84项已受理**发明专利（754 项总量 = 84 已受理 + 670 储备，见 §1.1 专利口径）；第三章记录2项软件著作权；第四章记录1项作品著作权；第五章列出120个核心词汇版权保护清单；第六章阐述版权保护策略；第七章分析专利与系统架构映射关系。

### 1.2 知识产权保护体系架构

元构知识产权保护体系采用"四层防护"架构：

**第一层：核心范式与理论保护层**
- 通过作品著作权保护"境生智能"理论体系
- 通过著作权保护《空间智能体宣言》等核心理论著作
- 通过核心词汇版权保护120个范式定义词汇
- 目的：确保思想源头与范式定义的原创性归属

**第二层：技术架构与核心方法保护层**
- 通过84项发明专利保护核心技术方案
- 通过软件著作权保护源代码实现
- 通过专利组合形成技术壁垒
- 目的：确保技术实现的可控性与排他性

**第三层：商标与品牌资产保护层**
- 核心商标：境生智能、空间智能体、元构等
- 应用商标：五大价值验证场景名称等
- 活动商标：奠基周、全球构建者大会等
- 目的：确保品牌认知的纯洁性

**第四层：商业秘密与生态控制层**
- 核心算法实现细节的商业秘密保护
- 通过开源许可证+CLA控制生态使用
- 通过授权协议规范合作伙伴使用
- 目的：在开放生态中保持主导权

### 1.3 创始人简介

**易霄**，元构智能体引擎创始人，"境生智能"范式提出者。

2026年1月，易霄先生首次系统提出"境生智能（Ambient-born Intelligence）"范式，主张智能的未来并非仅封装于机器人或云端，而是从物理环境本身生长、弥漫、涌现。该理论体系主张智能作为环境的内生属性，通过万物互联与数据流动实现动态生成和持续演化。

易霄先生随后完成以下知识产权创造：
- 撰写《空间智能体宣言——论"境生智能"与下一个文明纪元》，并于2026年2月12日获得国家版权局作品登记
- 系统规划并提交754项发明专利申请至国家知识产权局
- 完成元构智能体引擎V9.0技术白皮书与源程序的软件著作权登记
- 建立120个核心词汇版权保护清单

### 1.4 知识产权战略定位

元构知识产权体系的战略定位可概括为"三护一导"：

1. **护源头**：通过著作权与词汇版权，固化"境生智能"范式的原创性归属，确保思想源头不被篡夺
2. **护技术**：通过754项专利组合，保护从感知到执行的全链条技术方案，形成技术壁垒
3. **护品牌**：通过商标与品牌资产，确保"元构""境生智能""空间智能体"等核心品牌的纯洁性
4. **导生态**：通过开源许可证+授权协议+授权开发者计划，在开放中保持主导权，引导生态向符合价值观的方向发展

### 7.3 专利耦生度矩阵

#### 7.3.1 耦生度定义

**专利耦生度**：衡量两项专利之间技术相关性、协同价值、组合创新潜力的量化指标。

**计算公式**：

```
C_ij = f(技术相关性, 引用关系, 协同价值)
```

其中：
- 技术相关性：两项专利技术领域的重叠程度
- 引用关系：两项专利是否存在引用或被引用关系
- 协同价值：两项专利组合使用产生的增量价值

#### 7.3.2 耦生度阈值

| 耦生度范围 | 等级 | 含义 |

| 0.7-0.9 | A级（有效耦生） | 两项专利有效协同，组合使用产生显著增量 |
| 0.5-0.7 | B级（弱耦生） | 两项专利存在关联，组合使用有一定价值 |
| <0.5 | C级（无耦生） | 两项专利关联度低 |
