## 第一章 第20大元思想 · 易理工程学

### 1.1 为什么需要第20个

前 19 大元思想（双螺旋社会财富 / 耦生智能文明 / DCV六维价值 / 四步破局 / 政策牵引 /
社会主义耦生哲学 / 耦生辩证唯物主义 / 量子-生物-宇宙三重融合 / 易霄溯源论 / Skill中心论 /
现实驱动智能论 / Agentive OS / 新型工业化智能观 / 境生智能 / 创源计划 /
空间智能体 / 物理空间操作系统 / 空间智能协议 / 负熵责任引擎）
全部回答的是 **「系统应该是什么」**。

它们没有回答 **「面对一个具体局面，此刻该怎样推演」**。

第 20 大元思想补的正是这一层：**把《周易》以来的象数推演方法，从玄学语境剥离，
变成可计算、可验证、可追溯的工程方法**。它不预测未来，它给局面建模。

### 1.2 核心命题：态势模型

$$\text{态势模型} = f(\text{象},\ \text{变},\ \text{局},\ \text{机},\ \text{势},\ \text{应})$$

六个维度各自的可执行定义：

| 维度 | 含义 | 输入形态 | 可验证判据 |
|---|---|---|---|
| **象** | 当下可观测的状态截面 | 多维指标向量 | 维度数固定、值域明确、采样时刻标注 |
| **变** | 状态随时间的变化率与转折 | 时间序列 | 一阶/二阶差分可算，转折点可定位 |
| **局** | 所处的结构化格局（空间/层级/关系） | 图结构 / 九宫格 / 分层表 | 节点与边可枚举，层间关系可验证 |
| **机** | 临界点与可介入窗口 | 阈值函数 | 存在明确的触发条件与失效条件 |
| **势** | 累积的动能与方向 | 积分量 | 可对时间积分，方向可判定 |
| **应** | 介入后的响应与应期 | 反馈函数 | 有响应曲线，应期可计算 |

**关键纪律**：六维必须**同时给出**才能成模型。缺任一维，只能叫「观察」不能叫「态势」。

### 1.3 与前 19 大元思想的关系

- 它**不是**替代关系，是**操作层**关系：前 19 个给方向，第 20 个给「此刻怎么算」
- 它**必须**服从 A37 第一性原理：象数建模前先剥离「玄学惯例」
- 它**必须**服从 A38 对抗式审查：模型输出须经攻击者视角检验
- 它**必须**服从 D46：时空态势/组织诊断/周期研判/决策推演类任务**优先**象数建模
- 它**必须**服从 D47：每条断言标注四联（文言命题 + 现代数学等价 + 规则编号 + 置信度）

## 第二章 易理五公理（A39–A43）

> 蓝本第一卷 L752 已载「易理五公理顺延为 A39–A43」，本卷给出形式化表述与可执行判据。

| 编号 | 公理 | 形式化 | 可执行判据 | 违反后果 |
|---|---|---|---|---|
| **A39** | 变易公理 | `Model = (S, T)`，`S` 状态空间、`T` 转移函数 | 每个模型必须同时给出 `S` 与 `T`；只有 `S` 无 `T` = 静态快照，不是模型 | 无法推演，只能描述 |
| **A40** | 简易公理 | `System ≈ Symbolic_State_Space` | 复杂系统必须能被符号化降维；降维后维度数 ≤ 原始维度数 | 维数爆炸，不可计算 |
| **A41** | 不易公理 | `规则 ⊥ 状态`（规则与状态正交） | 规则不随状态改变；状态改变不修改规则 | 规则漂移，不可复现 |
| **A42** | 阴阳互补公理 | `耦生效率 = cos(θ)` | 两方方向向量夹角 θ；cos(θ)→1 为同向协同，→0 为互补，→−1 为对抗 | 误判互补为对抗 |
| **A43** | 天人同构公理 | 微观状态模式 ≅ 宏观状态模式 | 同一套象数规则可同时用于个体/组织/时局三层；三层输出结构同构 | 每层各写一套，不可复用 |

区间内 A31–A33、A37–A38 由包侧增量补入（A31 元进化五阶段循环 / A32 失败即起点 /

## 第七章 三处必须说清的边界

### 7.1 象数推演不是预测

本卷第一章明确：态势模型**给局面建模，不预测未来**。
输出是「当前局面的结构化描述 + 可能的转移路径 + 每条路径的置信度」，
不是「未来一定会怎样」。任何把置信度当概率承诺的用法都是误用。

### 7.2 玄学语境剥离是强制的（A37）

A37 第一性原理要求：象数建模前必须剥离「因为传统这么说」的假设。
具体而言：
- 保留：可由天文/历法公式精确计算的部分（节气、干支、月相）
- 保留：可形式化验证的规则（五行生克矩阵、卦变规则、九宫数理）
- 剥离：无法证伪的断语（吉凶祸福的具体应验）
- 剥离：依赖师承口诀而无公开推导路径的部分

### 7.3 置信度必须真实标定（D47）

D47 要求四联标注。**置信度不允许编造**：
- 有历史样本的，按命中率标定并注明样本量
- 无样本的，必须标「无样本依据，仅为规则推导」且置信度 ≤ 0.5
- 禁止把「规则的确定性」当成「结论的置信度」
