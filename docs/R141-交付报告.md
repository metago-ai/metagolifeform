## 十、第 10 批：把「做不到」再推一轮

**触发点**：目标要求「绝对不允许任何未实现」。第 8 批收口时我还剩 14 条标为「不支持」，
但我复核后发现其中 11 条是我的**分类太粗**，不是真的做不到。

**核心纠正（CORR-047）**：「契约产物是自然语言」不等于「需要大模型」。
自然语言有多种确定性生成方式：

| 方式 | 用在哪 | 为什么不需要模型 |
|---|---|---|
| **抽取**（选句不生成） | 时事摘要 | 从原文里选高分句子，一个字都不生成 |
| **模板填充** | 思想传记 / 负熵报告 | 产物是文本，但由数据决定 |
| **规则库匹配** | 摩擦致敬器 / 道在日常 / 非技术转化 | 特征触发预设策略 |
| **术语注释** | 政策翻译官 / 科技祛魅器 | 加注而非重写，保留原文结构 |
| **信号特征提取** | 生理信号解码器 | HRV 时域频域指标是纯数学 |

**核心纠正（CORR-048）**：政策翻译官第一版用「术语替换重写句子」，产物是
「…的钱政府给的钱。经提交申请官方审核后确定后…」——词对但句错。
**改成「术语内联注释」后通顺且信息无损。规则做不到「重写」时，退一步做「加注」。**

**结果**：不支持项从 **14 → 3**；597 条分布变为 `{526, 52, 11, 5, 3}`。
