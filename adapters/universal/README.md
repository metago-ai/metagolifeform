# universal — 通用适配路径

无专属适配器目录的任何 MCP / 规则注入型平台，都可用仓库根 `AGENTS.md`（母本）直接落地：
1. 法则：复制 AGENTS.md 母本内容（把"Trae"读作"当前平台"，或按目标平台手工替换平台措辞）到该平台的规则文件位。
2. 技能：复制 `skills/metago-*`（100 个）到平台技能目录。
3. MCP：按 `docs/MCP_MANUAL_CONFIG.md` 手工注册 metago + metago-algorithms 双服务器。

> 36.9.3 起本目录以 README 形式承载"通用路径"说明（此前为空目录）。
