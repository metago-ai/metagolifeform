# 需求追踪矩阵（RTM）

> UDGK 门禁 1 模板。把自然语言需求逐条翻译成「要求 → 代码 → 断言 → 证据」四列映射表。
> 用法：复制到项目 docs/rtm.md（或 scripts/init-delivery.cjs 自动生成空表）。一条需求一行；四列任一为空 = 门禁 FAIL。

| 编号 | 要求 | 代码位置 | 断言测试 | 验收证据 |
|------|------|----------|----------|----------|
| R-1 | （要做什么——可验证的一句话） | （文件:行 / 模块） | （e2e/asserts/xxx.spec.ts#用例名） | （截图路径 / 命令输出 / HTTP 状态码） |
| R-2 |  |  |  |  |

## 填写规则
1. 「要求」必须逐字来自需求文档，不得合并、不得省略（一条缺失 = 禁止往下）。
2. 「断言测试」写可机器执行的断言（DOM 形态断言优先），不接受"人工看过没问题"。
3. 「验收证据」写运行产物路径或输出摘录；禁止占位符。
4. 交付前运行 `node scripts/udgk/verify-delivery.cjs --strict`，本表全绿才允许宣告完成。
